# Zasoby projektu

Umieszczaj tutaj zasoby wymagane do uruchomienia świata, np.:

- `shaders/` — pliki GLSL (`.vert`, `.frag`, `.geom`, `.tesc`, `.tese`, `.comp`);
- `textures/` — tekstury koloru i danych;
- `models/` — modele oraz powiązane materiały.

Jeżeli zewnętrzny asset ma plik licencji albo wymaga oznaczenia autora,
zachowaj tę informację bezpośrednio obok danego assetu.
